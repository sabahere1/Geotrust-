Why This Idea Is Original

🔗
No Existing Web3 Product Owns This Combination
Braintrust (reputation-only, no escrow). Gitcoin (grants, not freelance). Request Network (invoicing, no credentials). LaborX (crypto escrow, but no portable credential NFTs and no Georgia focus). GeoTrust is the first to combine trustless escrow + portable on-chain reputation in one protocol, targeted at an underserved geography.
📍
Geography-First: Built for Where the Problem Is Sharpest
Rather than building another global generic tool, GeoTrust targets Georgia and the South Caucasus — an underserved region with a growing tech freelance community and zero crypto-native tooling. This is a beachhead, not a feature.
🏗️
Reputation as Infrastructure, Not a Product Feature
Credential NFTs are composable primitives — any marketplace, DAO, or hiring platform can query them. GeoTrust's reputation layer becomes a public good for the Solana ecosystem, not a walled garden.
Ambition
GeoTrust's credential layer becomes the default reputation primitive for Solana's freelance ecosystem.

09.5 · Proof of Build · Anchor Escrow Program

The Code Is Already Written

use anchor_lang::prelude::*;
use anchor_spl::token::{self, Token, TokenAccount, Transfer};

// Lock USDC into PDA vault
pub fn create_job(ctx: Context<CreateJob>,
    amount: u64, deadline: i64) -> Result<()> {
  let job = &mut ctx.accounts.job;
  job.amount = amount; job.deadline = deadline;
  job.status = JobStatus::Open;
  token::transfer(CpiContext::new(
    ctx.accounts.token_program.to_account_info(),
    Transfer { from: ctx.accounts.client_ata,
      to: ctx.accounts.vault,
      authority: ctx.accounts.client }),
  amount)?;  Ok(()) }

// Release USDC to freelancer
pub fn approve_work(ctx: Context<ApproveWork>,
    rating: u8) -> Result<()> {
  let job = &mut ctx.accounts.job;
  job.status = JobStatus::Completed;
  job.rating = rating;
  let amount = job.amount;
  token::transfer(CpiContext::new_with_signer(
    ctx.accounts.token_program.to_account_info(),
    Transfer { from: ctx.accounts.vault,
      to: ctx.accounts.freelancer_ata,
      authority: ctx.accounts.vault_authority },
    &[&[b"vault", job.key().as_ref(),
       &[ctx.bumps.vault_authority]]]),
  amount)?;  Ok(()) }
// Job State Machine
Open→InProgress
InProgress→Completed
InProgress→Disputed
Open→Refunded

accept_jobconfirm work
